Exponentiation

https://cses.fi/problemset/task/1095

Tu tarea consiste en calcular eficientemente los valores a^b modulo 10^9+7.

Ten en cuenta que en esta tarea asumimos que 0^0=1.

Input

La primera linea de entrada contiene un entero n: el numero de calculos.

A continuacion, hay n lineas, cada una con dos enteros a y b.

Output

Imprime cada valor de a^b modulo 10^9+7.

Restricciones

- 1 <= n <= 2*10^5
- 0 <= a, b <= 10^9

Ejemplo

Entrada
3
3 4
2 8
123 123
Salida
81
256
921450052
